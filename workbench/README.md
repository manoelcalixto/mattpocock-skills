# Workbench

This directory preserves skills that are not part of the installable Codex product:

- `in-progress/` — drafts that are not ready to promote
- `personal/` — skills tied to a maintainer's own setup
- `misc/` — retained experiments and harness-specific utilities
- `deprecated/` — historical skills that are no longer used

Workbench skills remain in their inherited form until they are deliberately promoted. They are outside the native plugin's configured skill surface and editable installer's default discovery, and are excluded from product documentation and promoted-skill validation.
