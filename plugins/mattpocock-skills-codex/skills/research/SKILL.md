description: Investigate a question against high-trust primary sources and capture cited findings as a Markdown file in the repo. Use for research, documentation, or API facts.
---

Investigate directly. If the user or repository instructions authorize delegation and a native Codex subagent is available, assign this bounded research task to it and wait for its report. Follow the current concurrency and Planning checkpoint rules.

Its job:

1. Investigate the question against **primary sources** (official docs, source code, specs, first-party APIs), not a secondary write-up of them. Follow every claim back to the source that owns it.
2. Write the findings to a single Markdown file, citing each claim's source.
3. Save it where the repo already keeps such notes; match the existing convention, and if there is none, put it somewhere sensible and say where.
